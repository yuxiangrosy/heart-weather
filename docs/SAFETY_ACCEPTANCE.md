# v0.2.1 数据安全验收（Issue #2）

## 环境与边界

- 基线：main `8eb14ed`（v0.2.0 + 交接文档）。
- 所有破坏性测试仅使用临时 localhost 源、全新浏览器上下文、合成日记；不读取生产站点或私人备份。
- 新增可复现测试：`npm ci && npx playwright install --with-deps chromium && npm test`。
- 自动检查由 PR 触发；不自动部署或合并。
- 本环境已通过 JavaScript 语法检查与 Chromium 141 headless shell 真实浏览器回归（2026-11-05）。完整 Chrome 启动受环境限制，改用标准 Playwright headless shell 成功运行；PR 自动检查作为后续持续验证。

## 自动覆盖范围

1. 同一源运行 git 历史 `5ee5776` 的真实 v0.1.2 app.js，写入带标签日记与景观；切换当前代码，逐项比较并确认数据库仍为 v1。
2. 从 UI 下载 JSON，编辑/删除后拒绝过期备份确认；导出本身不能标记已确认。
3. 实际文件输入选择 JSON，下载保护快照并显式确认后覆盖恢复；逐项比较心情/标签/景观，拒绝损坏校验文件。
4. 等待 Service Worker 控制，关闭页面、完全断网、新开页面，离线写入并联网重开确认记录存在。此项是浏览器新页面冷启动，不等同 iOS 杀进程后冷启动。
5. 35 天景观分页、减少动态效果、离开小岛取消动画循环、捕获页面异常。
