# 🌤️ 心情天气 · V0.1.2（iPhone 个人体验版）

这是一款**可以运行的离线优先 PWA**，不是静态图片，也不需要 App Store。第一次上线后，用 iPhone Safari 打开并「添加到主屏幕」，即可从桌面图标使用。

> 开发阶段：V0.1.2 测试版，暂时请使用**测试日记**而不是唯一一份重要私人日记。务必在 iPhone 实测备份和恢复以后，再开始长期记录。

## 目前能做什么

- 选择 16 种天气（默认先展示 8 种，点击更多可展开全部）记录心情，最多添加 3 个选填情绪标签，文字可选（最多 1000 字）。一天可记多次。
- 编辑、删除历史记录，心情日历显示**当日最新记录**和记录次数。
- 已有的 7 种天气 ID 保持不变；新天气各自有岛屿植物，历史记录不丢失。
- 每周、每月查看天气分布：清楚区分「记录条数」和「记录天数」。并查看高频情绪标签。目前是本地模板总结，**不是 AI 总结**。
- 天气岛初始只有少量小草和石头；心情会改变天空；**每个有记录的日期最多长出 1 处持久景观**。不记录不会让植物枯萎。可点击景观回看关联记录。
- IndexedDB 离线本地保存、记录草稿保存。
- 导出带 SHA-256 完整性校验的 JSON 备份；导入前预览、要求保护当前记录，确认后全量恢复。
- Service Worker 缓存、主屏幕应用图标。

宠物、多个岛屿、AI 总结、鼓励人物、出气屋与精细动画尚未开发，已保留在产品路线图。

## 最简单部署方式：Cloudflare Pages（适合 iPhone 自用）

1. 在 Mac 下载发布 ZIP（见聊天中的下载链接）。ZIP 的**顶层即 `index.html`、`app.js`、`styles.css` 等文件**；不要再额外包一层目录。
2. 打开 https://dash.cloudflare.com/ ，登录后进入 **Workers & Pages → Create application → Drag and drop your files**（界面名称可能更新）。
3. 建立项目，如 `my-heart-weather`，上传整个发布 ZIP，选择 **Deploy site**。
4. 部署后会得到类似 `https://my-heart-weather.pages.dev/` 的地址。这个示例地址**不是已经为你创建好的站点**。
5. 在 iPhone Safari 打开你部署好的真实地址 → 分享 → **添加到主屏幕** → 开启 **作为网页 App 打开** → 添加。
6. 今后持续从**同一个主屏幕图标**打开。首次需要联网下载资源，之后在资源缓存完成时可离线使用。

> 部署的只是网页应用代码，不包含你的个人日记。用户日记默认只留在当前设备的 IndexedDB。

Cloudflare Pages Direct Upload 官方说明：https://developers.cloudflare.com/pages/get-started/direct-upload/
Apple 官方添加网页 App 说明：https://support.apple.com/guide/iphone/open-as-web-app-iphea86e5236/ios

## 备份与恢复（必须理解）

1. 每次记录自动保存在本机 IndexedDB。**这不是 iCloud 自动同步。**
2. 在「设置与备份」点「创建完整备份文件」，通过「文件」App 确认文件已保存到 **iCloud Drive**，然后返回应用点「我已将备份存入 iCloud Drive」。
3. 如果需要恢复，打开同一页面、选取 `.moodbackup.json` 文件。系统会校验 SHA-256 和数据格式，并要求你先导出当前数据保护快照；最终恢复是**全量替换，不会合并**。
4. 明文 JSON 备份包含心情文字，请放在可信位置。当前版本没有备份加密功能。
5. 更换主屏幕图标的来源网址、更换域名、删除 PWA 或清理网站数据都可能导致看不到或丢失本机记录。一定要保留独立备份。

**校验不能替代真正的异地备份**，也不能保证系统永远不会删除本机数据。

## 开发与本机运行

所有代码均为原生 HTML/CSS/JS，无第三方库，无 CDN，无后端请求，也不需要 npm。此版本为了方便测试暂时不使用 React / Dexie；后续迁移时数据格式要保持兼容。

```bash
cd heart-weather-pwa
python3 -m http.server 4173
```

Mac 浏览器访问 `http://localhost:4173/`。不要直接双击 HTML 文件验证存储与加密备份。iPhone 访问时必须使用部署后的 HTTPS 地址，而不是 Mac 的 localhost。

## 项目文件

- `index.html`：页面入口
- `styles.css`：手机优先的像素奶油色 UI
- `app.js`：记录、日历、统计、小岛、IndexedDB、备份恢复
- `sw.js`：离线缓存（缓存版本 v0.1.2）
- `manifest.webmanifest`、`icons/`：主屏幕入口
- `tests/`：在浏览器内模拟数据库的集成测试（**不能替代真实设备测试**）

### 从 v0.1.1 升级至 v0.1.2

- **保持相同站点地址、相同主屏幕入口。** 在 Cloudflare Pages 中更新原项目，不创建新站点。
- 先在旧版「设置与备份」导出原始备份到 iCloud Drive，再上传新版 ZIP。首次上线后可联网重新打开或关闭再打开，使 Service Worker 更新生效。
- v0.1.2 保留旧数据库名称和对象存储格式；旧记录无需迁移，新记录额外包含可选的 `tags` 字段。旧版 v0.1.1 备份可导入新版。反过来不保证新版备份能在旧版导入（新增天气旧版不认识）。
- **不要把新版部署到另一个域名后，误以为旧记录自动同步过去**：本地数据库绑定站点来源；有变更则通过已验证的备份恢复。
